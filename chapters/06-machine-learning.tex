\chapter{言葉が応答になるまで}
\label{chap:machine-learning}

\begin{chapterabstract}
要求はサーバーへ届き、アプリは注文データから「明日の午後」という事実を得ました。残る仕事は、その事実と利用者の質問を受け取り、自然な応答へ変えることです。ここで物語の中にあった大きな箱、言語モデルの内側へ入ります。

文字列はそのままではモデルへ渡せません。文を小さな単位へ分け、その単位を数へ置き換え、さらに複数の数をひとまとまりにします。モデルは、その数のまとまりを何段階も変換します。なぜ変換の規則をデータから決められるのかを理解するため、入力と出力の対応、変化の測り方、不確実さの表し方から順に始めます。専門用語は数式より先に日常語で意味を置き、最後に一単位ずつ応答が生まれるところまでつなぎます。
\end{chapterabstract}


\section{関数・ベクトル・行列}
\label{sec:06-machine-learning-01}

サーバーへ届いた質問をモデルへ渡すには、言葉を計算できる形へ変えなければなりません。モデルの内側では、入力と出力の対応を表す関数、複数の数を順序付きで並べるベクトル、多数のベクトルをまとめて変換する行列が共通の言葉になります。

\begingroup
\begingroup
\paragraph{関数}
        ある値を受け取ったとき、決めた規則によって一つの値を返す対応が\term{関数}です。受け取る値を\term{入力}、返す値を\term{出力}といいます。$y=f(x)$は「関数$f$へ入力$x$を渡すと出力$y$になる」と読みます。入力と出力を座標上の点として描いたものがグラフで、入力を変えたとき出力がどう変わるかを見せます。

      \centering
      \begin{tikzpicture}[x=7mm,y=5mm,every node/.append style={font=\scriptsize}]
        \draw[->,draw=PaleGray] (-2.3,0)--(2.5,0) node[right] {$x$};
        \draw[->,draw=PaleGray] (0,-.5)--(0,4.8) node[above] {$f(x)$};
        \draw[draw=MutedBlue,line width=.8pt] plot[smooth] coordinates {(-2,4)(-1.5,2.25)(-1,1)(-.5,.25)(0,0)(.5,.25)(1,1)(1.5,2.25)(2,4)};
        \node[right] at (1.5,3.5) {$x^2$};
      \end{tikzpicture}
\par
\endgroup
\medskip
\begingroup
\paragraph{ベクトル}
        複数の数を順番のある一列へまとめたものが\term{ベクトル}です。一個一個の数を\term{成分}、成分の個数を\term{次元}といいます。$\mathbf{x}=(x_1,\ldots,x_d)^\top$は、$d$個の成分を縦に並べるという意味です。右肩の$\top$は、横と縦を入れ替える\term{転置}を表します。

        同じ数の成分を持つ二つのベクトルで、対応する成分を掛けてすべて足した値が\term{内積}です。$\mathbf{w}^\top\mathbf{x}=w_1x_1+\cdots+w_dx_d$となり、各$x_i$の影響を$w_i$で調整して足す\term{重み付き和}として読めます。

\paragraph{行列}
        数を行と列の長方形に並べたものが\term{行列}です。$W\mathbf{x}$では、行列$W$の各行とベクトル$\mathbf{x}$の内積を計算し、別のベクトルを作ります。足し算と定数倍の関係を保つ変換を\term{線形変換}といい、行列で表せます。

\paragraph{形状}
        行列やベクトルが各方向にいくつの成分を持つかを\term{形状}といいます。$\mathbb{R}$は実数、すなわち負の数、0、正の数、小数を含む普通の数の集まりです。$W\in\mathbb{R}^{m\times d}$は$W$が$m$行$d$列、$\mathbf{x}\in\mathbb{R}^{d}$は$x$が$d$成分という意味なので、$W\mathbf{x}$は$m$成分になります。

\par
\endgroup
\par
\endgroup


\section{微分と勾配}
\label{sec:06-machine-learning-02}

行列の値を決めれば関数は動きますが、良い応答を生む値を人が一つずつ設定することはできません。出力の誤りが、どの値をどちらへ動かすと減るかを知るため、関数の変化を微分と勾配で読みます。

\begingroup
\begingroup
\paragraph{微分}
        入力をほんの少し変えたとき、出力がどの向きへどれほど変わるかを表す値が\term{微分}です。一つの入力を持つ関数$f$の点$x$では、まず入力を$h$だけ変えたときの出力差を$h$で割ります。$h$を限りなく0へ近づけた値として次のように定義します。
        \[
          f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}
        \]
        「限りなく近づけた先の値」を\term{極限}といいます。微分は点$x$のすぐ近くにおける出力の変化率で、グラフへその点で触れる直線である接線の傾きとして読めます。

\paragraph{偏微分}
        複数の入力を持つ関数で、ほかの入力を動かさず、一つだけを少し変えたときの変化率が\term{偏微分}です。どの入力が出力へどう影響するかを別々に見ます。

\par
\endgroup
\medskip
\begingroup
\paragraph{勾配}
        モデルが内部に持ち、学習によって値を調整する数を\term{パラメータ}といいます。複数のパラメータを$\boldsymbol{\theta}$で表します。出力の悪さを表す関数$L$について、各パラメータの偏微分を一つのベクトルへ並べたものが\term{勾配}です。記号$\nabla$はナブラと読み、勾配を表します。
        \[
          \nabla L(\boldsymbol{\theta})=
          \left(
          \frac{\partial L}{\partial\theta_1},\ldots,
          \frac{\partial L}{\partial\theta_d}
          \right)^\top
        \]
        勾配の各成分は、対応するパラメータを少し増やしたとき$L$がどれほど変わるかを示します。

\paragraph{最小化}
        勾配は現在地点の近くで$L$が最も増える向きを示します。その反対の$-\nabla L$側へ小さく動かすと、現在地点の近くでは$L$を下げられます。遠くまで同じ形とは限らないため、これは局所的、すなわち近い範囲での根拠です。

\par
\endgroup
\par
\endgroup


\section{確率と期待値}
\label{sec:06-machine-learning-03}

同じ入力に常に唯一の正解があるとは限らず、観測データにもばらつきがあります。ある出来事がどれほど起こりやすいかを0から1までの数で表したものが\term{確率}です。0は起こらない、1は必ず起こることを表します。何が起こるか確定していない状態を\term{不確実さ}と呼びます。

\begingroup
\begingroup
\paragraph{条件付き確率}
        確率を考える対象の出来事を\term{事象}といいます。事象$B$が起きたと分かった後で、事象$A$が起こる確率を\term{条件付き確率}といい、$P(A\mid B)$と書きます。$A$と$B$が同時に起こる確率を、$B$が起こる確率で割って求めます。
        \[
          P(A\mid B)=\frac{P(A\cap B)}{P(B)}
          \quad (P(B)>0)
        \]
        $A\cap B$はAとBがともに起きる事象、縦線$\mid$は「Bという条件の下で」を意味します。

\paragraph{独立との違い}
        $B$を知っても$A$の確率が変わらない関係を\term{独立}といいます。このとき$P(A\mid B)=P(A)$です。一般の二事象は独立とは限りません。

\par
\endgroup
\medskip
\begingroup
\paragraph{離散変数の期待値}
        結果によって値が決まる変数を\term{確率変数}といいます。その値が0、1、2のように飛び飛びなら\term{離散確率変数}です。起こり得る各値を、その確率で重み付けして足した平均が\term{期待値}です。
        \[
          \mathbb{E}[X]=\sum_x xP(X=x)
        \]
        起こり得る値を確率で重み付けした平均です。必ずしも実際に取る値ではありません。

\paragraph{分布の前提}
        確率変数の各値がどの確率で現れるかをまとめたものが\term{確率分布}です。現実のどんな仕組みからデータが生まれるかを\term{データ生成過程}と呼びます。確率はこの過程について置くモデルに依存します。

        全体から実際に観測した有限個の例を\term{標本}といいます。標本から計算した確率や平均は推定値であり、データ生成過程全体の真の値と必ず一致するわけではありません。

\par
\endgroup
\par
\endgroup


\section{機械学習}
\label{sec:06-machine-learning-04}

関数を変え、誤りを測り、不確実さを扱う道具がそろいました。すべての判断規則を開発者が直接書く代わりに、多数の例から関数のパラメータを調整する方法が\term{機械学習}です。入力から出力を計算する関数の構造と、調整後のパラメータをまとめて\term{モデル}と呼びます。

\begingroup
  \centering
  \begin{tikzpicture}[node distance=4mm,every node/.append style={font=\scriptsize}]
    \node[box] (data) {訓練データ\\$(\mathbf{x},y)$};
    \node[accentbox,right=of data] (learn) {学習アルゴリズム};
    \node[box,right=of learn] (model) {モデル\\$f_{\boldsymbol{\theta}}$};
    \node[accentbox,right=of model] (pred) {未知の入力へ予測};
    \draw[flow] (data)--(learn);
    \draw[flow] (learn)--(model);
    \draw[flow] (model)--(pred);
  \end{tikzpicture}
  \vspace{5mm}
\begingroup
\paragraph{ルールを書く処理}
        開発者が条件と処理を直接記述します。要件が明確で、例外を列挙できる処理に適します。

\par
\endgroup
\medskip
\begingroup
\paragraph{データから学ぶ処理}
        モデルの誤りを表す損失を小さくするパラメータを、例から求めます。観測したデータから未知の値を見積もることを\term{推定}といいます。画像中の対象や文の意図を見分ける認識、将来や未知の値を出す予測など、規則を手で列挙しにくい処理に使います。

\par
\endgroup
  \takeaway{実システムでは、明示的なルールと学習モデルを組み合わせる場合があります。}
\par
\endgroup


\section{学習と推論}
\label{sec:06-machine-learning-05}

モデルが作られる時間と、利用者の質問へ答える時間は分けて考えます。多くの例からパラメータを更新する処理が\term{学習}であり、学習後の固定したパラメータへ新しい入力を通して出力を得る処理が\term{推論}です。物語の現在地は推論ですが、その振る舞いの理由は学習にあります。

\begingroup
\begingroup
\paragraph{特徴量 $\mathbf{x}$}
        予測に使う入力の一つ一つの測定値や表現を\term{特徴量}といいます。年齢のような数値、商品種別のような分類名、画像を構成する色の点である画素、文の小さな単位を数へ変えた表現などがあります。複数の特徴量をベクトル$\mathbf{x}$へまとめます。

\paragraph{正解ラベル $y$}
        入力と目標出力の組から学ぶ方法を\term{教師あり学習}といいます。その目標出力が\term{正解ラベル}です。人が例へ正解を付ける作業を\term{注釈}と呼びます。測定の誤差、注釈者ごとの差、予測時には得られない将来情報の混入を確認します。

\par
\endgroup
\medskip
\begingroup
\paragraph{学習}
        訓練例を使い、損失が小さくなるようパラメータ$\boldsymbol{\theta}$を更新します。

\paragraph{推論}
        学習済みパラメータを固定し、新しい$\mathbf{x}$から予測$\hat{y}=f_{\boldsymbol{\theta}}(\mathbf{x})$を計算します。

\par
\endgroup
  \vspace{4mm}
\paragraph{モデルとデータ}
    学習に使う例の集合が\term{訓練データ}です。モデルは訓練データの傾向をパラメータへ反映しますが、各事実を完全に保存し、いつでも正確に再現するデータベースではありません。

\par
\endgroup


\section{データ分割}
\label{sec:06-machine-learning-06}

学習に使った例へよく合うだけでは、新しい質問へ答えられるか分かりません。手元のデータを用途の異なる集合へ分けることを\term{データ分割}といいます。パラメータを決める訓練データ、途中の設計選択に使う\term{検証データ}、最後まで学習と選択に使わず最終性能を測る\term{テストデータ}へ分けます。

\begingroup
  \noindent
  \begin{tabularx}{\textwidth}{@{}lYY@{}}
    \toprule
    分割 & 使い方 & 避けること\\
    \midrule
    訓練データ & パラメータを最適化する & 評価対象へ同じ例を使う\\
    検証データ & モデル、正則化、しきい値などを選ぶ & 選択を繰り返した後も未使用とみなす\\
    テストデータ & 最終候補の汎化性能を一度評価する & 結果を見て設計を直し続ける\\
    \bottomrule
  \end{tabularx}
  \vspace{4mm}
\paragraph{分割単位}
    同じ利用者の似た例、同じ文書の複製、時間的に未来の情報が分割をまたぐと、運用時には得られない手掛かりが学習側から評価側へ漏れます。この問題を\term{データ漏洩}といいます。同じ元から来た例をまとめ、運用時の時間順を反映して分けます。

\par
\endgroup


\section{損失関数}
\label{sec:06-machine-learning-07}

「良いモデル」という言葉を更新計算へつなぐには、予測と正解のずれを数へ変える必要があります。一例の予測がどれほど悪いかを一つの数で返す関数が\term{損失関数}です。値が小さいほど望ましいよう定め、学習は多くの例で損失が小さくなるパラメータを探します。

\begingroup
\begingroup
\paragraph{経験損失}
        手元で観測した訓練例それぞれの損失を平均した値が\term{経験損失}です。式の$n$は例の数、$i$は何番目の例か、$\ell$は一例の損失を表します。
        \[
          \hat{R}(\boldsymbol{\theta})=
          \frac{1}{n}\sum_{i=1}^{n}
          \ell\bigl(f_{\boldsymbol{\theta}}(\mathbf{x}_i),y_i\bigr)
        \]
        訓練例上の誤りを平均します。

\paragraph{例}
        連続した数値を予測する問題を\term{回帰}、入力を決めた種類のどれかへ分ける問題を\term{分類}といいます。回帰では予測と正解の差を二乗する\term{二乗誤差}、分類では正解クラスへ低い確率を出すほど大きく罰する\term{交差エントロピー}などを使います。

\par
\endgroup
\medskip
\begingroup
\paragraph{最適化}
        選んだパラメータの良さを表し、最小または最大にしたい関数を\term{目的関数}といいます。目的関数を最も良くするパラメータを探す処理が\term{最適化}です。式を解いて直接求める解析解、勾配を使う方法、無作為に選んだ例で近似する方法などがあります。

        関数のグラフ上でどの二点を選んでも、その二点を結ぶ線分がグラフより下へ出ない形を\term{凸}といいます。途中に独立した谷が生じない形です。そうでない非凸な問題には複数の谷があり得るため、全範囲で最良の\term{大域最適解}へ到達する保証がない場合があります。

\paragraph{指標との違い}
        モデルを比較するために測る値を\term{評価指標}といいます。微分しやすく学習に使える損失と、業務で重視する件数、費用、安全性の指標が異なることがあります。両者が期待どおり結び付くかを確かめます。

\par
\endgroup
  \source{MIT 6.390, “Machine Learning” notes}
\par
\endgroup


\section{多項式回帰}
\label{sec:06-machine-learning-08}

大きな言語モデルへ進む前に、見通しのよい小さな問題で学習の全体を見ます。$x^2$や$x^3$のような、変数の0以上の整数乗を足して作る式が\term{多項式}です。多項式を使って入力から連続値を予測する方法が\term{多項式回帰}です。曲線を複雑にすると何が良くなり、何が危うくなるかを図で追えます。

\begingroup
\begingroup
      \centering
      \begin{tikzpicture}[x=6.5mm,y=6.5mm,every node/.append style={font=\scriptsize}]
        \draw[->,draw=PaleGray] (-.2,0)--(6.5,0) node[right] {$x$};
        \draw[->,draw=PaleGray] (0,-.2)--(0,4.5) node[above] {$y$};
        \foreach \x/\y in {.5/.7,1.2/1.4,2/1.8,2.8/2.3,3.6/2.5,4.4/3.1,5.2/3.6,5.8/3.7}{
          \fill[DeepNavy] (\x,\y) circle (1.2pt);
        }
        \draw[draw=MutedBlue,line width=.8pt] plot[smooth] coordinates {(.3,.55)(1,1.15)(2,1.85)(3,2.25)(4,2.75)(5,3.35)(6,3.85)};
      \end{tikzpicture}
\par
\endgroup
\medskip
\begingroup
\paragraph{モデル}
        {\centering$\displaystyle f(x;\mathbf{w})=\sum_{j=0}^{M}w_jx^j$\par}
        $w_j$は各項の重み、$x^j$の$j$は何乗するかを示します。最も大きい指数$M$を\term{次数}といい、次数を増やすほど多様な曲線を表せます。

\paragraph{パラメータに対する線形性}
        入力$x$には多項式ですが、重み$\mathbf{w}$については各重みを定数倍して足すだけなので線形です。$(1,x,\ldots,x^M)$を新しい特徴量のベクトルとして見れば、重みとの内積になります。

\par
\endgroup
  \takeaway{表現力を増やすことと、未知データを正しく予測することは同じではありません。}
\par
\endgroup


\section{最小二乗法}
\label{sec:06-machine-learning-09}

回帰の曲線をデータへ合わせるため、予測値と観測値の差を二乗し、すべて足した量を最小にする方法が\term{最小二乗法}です。差をそのまま足すと正負が打ち消し合うため、二乗します。行列表現へまとめると、個々の点で起きていたずれが一つの目的関数になります。

\begingroup
\begingroup
\paragraph{目的関数}
        予測値と実際に観測した値の差を\term{残差}といいます。最小二乗法では残差を二乗し、その総和を最小化します。
        \[
          E(\mathbf{w})=
          \frac{1}{2}\sum_{i=1}^{n}
          \left(f(x_i;\mathbf{w})-y_i\right)^2
        \]
        正負の残差が相殺しないよう二乗し、大きな誤差を強く罰します。

\paragraph{行列表現}
        各訓練例の特徴量ベクトルを一行ずつ並べたものを\term{設計行列}$\Phi$といいます。$\Phi\mathbf{w}$は全例の予測、$\mathbf{y}$は全例の正解です。記号$\lVert\mathbf{v}\rVert$はベクトルの長さを表す\term{ノルム}で、ここでは各成分の二乗和の平方根です。したがって$E(\mathbf{w})=\frac12\lVert\Phi\mathbf{w}-\mathbf{y}\rVert^2$は残差二乗和です。

\par
\endgroup
\medskip
\begingroup
\paragraph{解き方}
        設計行列の列に重複した情報がなく、重みを区別するために十分な条件を持つことを\term{フルランク}といいます。この場合、微分を0と置いた\term{正規方程式}から解を求められます。

        ただし、有限桁のコンピュータで誤差を抑えて計算する\term{数値計算}では、行列を掛けると単位行列になる逆行列を直接作らず、行列を扱いやすい形の積へ分けるQR分解や特異値分解（SVD）を使う方法があります。ここでは名称の暗記より、「数式上同じでも計算の安定性が違う」と押さえます。

\paragraph{最小二乗法の仮定}
        ほかの例から大きく離れた観測値を\term{外れ値}といいます。差を二乗する損失は、大きな残差をさらに大きくするため外れ値へ敏感です。誤差の分布、測定精度、業務目的に応じて別の損失も検討します。

\par
\endgroup
\par
\endgroup


\section{未学習と過学習}
\label{sec:06-machine-learning-10}

曲線が単純すぎる、学習が足りないなどの理由で、訓練データにある関係さえ十分に捉えられない状態が\term{未学習}です。反対に、訓練データへよく合うものの、偶然の揺れまで拾い、未知の入力では誤りが増える状態が\term{過学習}です。流暢な応答を返すモデルでも、見たことのない条件で正しいとは限らない理由がここから始まります。

\begingroup
  \noindent
  \begin{tabularx}{\textwidth}{@{}lYYY@{}}
    \toprule
    状態 & 訓練データ & 未知データ & 主な兆候\\
    \midrule
    未学習 & 誤差が大きい & 誤差が大きい & 表現力不足、学習不足、特徴不足\\
    適切 & 誤差が小さい & 誤差も小さい & 安定した検証性能\\
    過学習 & 誤差が非常に小さい & 誤差が大きい & ノイズや偶然の特徴へ適合\\
    \bottomrule
  \end{tabularx}
  \vspace{4mm}
\begingroup
\paragraph{モデルの複雑さ}
        モデルがどれほど多様な入力と出力の関係を表せるかを\term{モデルの複雑さ}と呼びます。パラメータ数だけでなく、パラメータへ課す制約、特徴量、データ量、最適化方法、学習回数が、実際に使われる複雑さへ影響します。

\par
\endgroup
\medskip
\begingroup
\paragraph{学習曲線}
        訓練と検証の損失や指標を、データ量または学習回数に対して描いたグラフが\term{学習曲線}です。訓練だけ改善して検証が悪化し始めれば、過学習の手掛かりになります。

\par
\endgroup
\par
\endgroup


\section{正則化}
\label{sec:06-machine-learning-11}

複雑なモデルが訓練データの細かな揺れへ合わせ過ぎないよう、目的関数やパラメータへ制約を加えることが\term{正則化}です。パラメータの大きさへ代価を課す方法は、表現力をすべて捨てるのではなく、未知の入力へ持ち出せる比較的単純な規則を選びやすくします。

\begingroup
\begingroup
\paragraph{L2正則化の例}
        \term{L2正則化}では、元の損失へ重みの二乗和を加えます。L2は、ベクトルの各成分を二乗して足す長さの測り方を指します。
        \[
          E_{\lambda}(\mathbf{w})=
          E(\mathbf{w})+\frac{\lambda}{2}\lVert\mathbf{w}\rVert_2^2
        \]
        大きな係数へ罰則を加え、データの小さな変動に対する曲線の過敏さを抑えます。

\paragraph{ハイパーパラメータ}
        学習によって直接更新する重みではなく、学習の進め方やモデルの構成を外側から決める値を\term{ハイパーパラメータ}といいます。$\lambda$は正則化の強さを表し、検証データなどで選びます。

\par
\endgroup
\medskip
\begingroup
\paragraph{汎化性能}
        訓練に使っていない、運用時と同じ条件から来る例へどれだけ良く予測できるかを\term{汎化性能}といいます。訓練損失の低さだけでは測れません。

\paragraph{正則化の限界}
        データ漏洩、分布差、誤ったラベル、評価指標の不一致があれば、正則化しても妥当な評価にはなりません。

\par
\endgroup
\par
\endgroup


\section{ベイズの式}
\label{sec:06-machine-learning-12}

新しい証拠を得たとき、ある原因の見込みをどう更新するかを考えます。観測前の見込みと、その原因なら観測がどれほど起きやすいかを組み合わせ、観測後の見込みへ変える関係が\term{ベイズの式}です。名前はThomas Bayesに由来します。障害調査で証拠を得るたび仮説の見込みを更新するときにも同じ向きが現れます。

\begingroup
\begingroup
\paragraph{ベイズの式}
        観測$B$を得た後の事象$A$の確率は、次の式で分解できます。
        \[
          P(C\mid\mathbf{x})=
          \frac{P(\mathbf{x}\mid C)P(C)}
               {P(\mathbf{x})}
        \]
        $C$は原因やクラス、$\mathbf{x}$は観測です。$P(C)$は観測前の見込みである\term{事前確率}、$P(\mathbf{x}\mid C)$は原因$C$なら観測$\mathbf{x}$がどれほど起きやすいかを表す\term{尤度}、$P(C\mid\mathbf{x})$は観測後の見込みである\term{事後確率}です。分母$P(\mathbf{x})$は全原因を通した観測自体の確率で、結果を合計1へそろえます。

\paragraph{不確実さの表現}
        分類結果を一つのラベルだけでなく、条件付き確率として表すと、しきい値や損失を後から組み合わせられます。

\par
\endgroup
\medskip
\begingroup
\paragraph{例：検査}
        実際に対象である例を陽性と判定できる割合が\term{感度}、対象でない例を陰性と判定できる割合が\term{特異度}です。対象自体がまれなら、両者が高い検査でも、陽性後に本当に対象である確率は事前確率に強く影響されます。

\paragraph{確率の品質}
        モデルが0.8と出した例を多数集めたとき、実際にも約80\%が正しいという対応を\term{校正}といいます。分類精度が高くても確率の校正が良いとは限らないため、別に評価します。

\par
\endgroup
\par
\endgroup


\section{確率的意思決定}
\label{sec:06-machine-learning-13}

確率を出しただけでは、アプリが何をすべきかは決まりません。起こり得る各結果の確率と、その結果が生む損失を組み合わせて行動を選ぶことが\term{確率的意思決定}です。誤って答える損失、回答を控える損失、人へ確認を求める損失を比べます。

\begingroup
\begingroup
\paragraph{期待損失}
        真の状態$C$で行動$a$を選んだときの損失を$L(a,C)$とします。各状態の損失を、その状態の事後確率で重み付けして足した値が\term{期待損失}です。
        \[
          R(a\mid\mathbf{x})=
          \sum_C L(a,C)P(C\mid\mathbf{x})
        \]
        が小さい行動を選びます。

\par
\endgroup
\medskip
\begingroup
\paragraph{しきい値}
        モデルの数値を二つの判断へ分ける境目が\term{しきい値}です。本当は対象なのに陰性とする\term{見逃し}と、対象でないのに陽性とする\term{誤警報}の損失が違えば、確率0.5が最適とは限りません。

\paragraph{決定境界}
        特徴量を座標として入力を置く空間を\term{特徴空間}といいます。その空間上で選ぶクラスが切り替わる点の集まりが\term{決定境界}です。モデル出力に加え、しきい値や損失で位置が変わります。

\par
\endgroup
  \takeaway{予測モデルと、その出力を使う業務判断を分けて評価します。}
\par
\endgroup


\section{線形識別}
\label{sec:06-machine-learning-14}

連続値の予測から、入力を複数の側へ分ける問題へ進みます。特徴量の重み付き和を計算し、直線や平面のどちら側にあるかで分類する方法を\term{線形識別}といいます。単純な形だからこそ、何を表せて何を表せないかが見えます。

\begingroup
\begingroup
      \centering
      \begin{tikzpicture}[x=10mm,y=9mm,every node/.append style={font=\scriptsize}]
        \draw[->,draw=PaleGray] (0,0)--(5.5,0) node[right] {$x_1$};
        \draw[->,draw=PaleGray] (0,0)--(0,4.8) node[above] {$x_2$};
        \foreach \x/\y in {.7/3.4,1.2/2.8,1.7/3.7,2.1/2.5}{\fill[MutedBlue] (\x,\y) circle (1.5pt);}
        \foreach \x/\y in {3.1/1.3,3.7/2,4.3/1.1,4.7/2.3}{\draw[DeepNavy,fill=CardWhite] (\x,\y) circle (1.7pt);}
        \draw[draw=DeepNavy,line width=.8pt] (.8,.5)--(4.4,4.3);
        \node[rotate=46] at (3.6,4.15) {$\mathbf{w}^\top\mathbf{x}+b=0$};
      \end{tikzpicture}
\par
\endgroup
\medskip
\begingroup
\paragraph{2クラス分類}
        二種類のどちらかへ分ける問題が\term{2クラス分類}です。線形識別関数は、入力と重みの内積に、境界位置をずらす定数である\term{バイアス}$b$を加え、結果が正か負かを判定します。
        \[
          g(\mathbf{x})=\mathbf{w}^\top\mathbf{x}+b,\qquad
          \hat{y}=\operatorname{sign}(g(\mathbf{x}))
        \]
        $\operatorname{sign}$は正なら$+1$、負なら$-1$を返す関数です。$\mathbf{w}$は境界へ直角な向きを示す\term{法線ベクトル}、$b$は境界の位置を定めます。

\paragraph{線形分離可能}
        二次元では直線、三次元では平面、その高次元版を\term{超平面}と呼びます。一つの直線または超平面で、訓練例を誤りなく二群へ分けられる状態が\term{線形分離可能}です。

\par
\endgroup
\par
\endgroup


\section{パーセプトロン}
\label{sec:06-machine-learning-15}

線形境界をデータから動かす単純な学習モデルが\term{パーセプトロン}です。入力の重み付き和から二クラスを判定し、誤分類した例に出会うたび、その例を正しい側へ移す方向に重みを更新します。局所的な誤りがパラメータの変化へ戻る、学習の原型です。

\begingroup
\begingroup
\paragraph{更新則}
        ラベル$y_i\in\{-1,+1\}$の例で$y_i(\mathbf{w}^\top\mathbf{x}_i+b)\le0$なら、
        \[
          \mathbf{w}\leftarrow\mathbf{w}+\eta y_i\mathbf{x}_i,\qquad
          b\leftarrow b+\eta y_i
        \]
        と更新します。$\eta$は一回に重みを動かす大きさで、\term{学習率}と呼びます。左矢印は、右辺で計算した新しい値へ置き換えるという意味です。

\paragraph{直観}
        正例を正側へ、負例を負側へ動かす方向に境界を調整します。

\par
\endgroup
\medskip
\begingroup
\paragraph{収束の条件}
        更新を繰り返した値が一定の値や条件へ近づくことを\term{収束}といいます。訓練データが線形分離可能なら、例を繰り返し提示するパーセプトロンは有限回の更新で分離する重みへ到達します。

\paragraph{条件外}
        分離できないデータでは更新が続き得ます。停止条件、平均化、別の損失やモデルを検討します。

\par
\endgroup
\par
\endgroup


\section{XOR}
\label{sec:06-machine-learning-16}

一枚の直線では、どんな規則でも分けられるわけではありません。XORは小さな例でその限界を示します。入力を一度別の表現へ写してから境界を引く必要があり、多層化へ進む理由が生まれます。

\begingroup
\begingroup
      \centering
      \begin{tikzpicture}[x=24mm,y=20mm,every node/.append style={font=\scriptsize}]
        \draw[->,draw=PaleGray] (-.1,0)--(1.4,0) node[right] {$x_1$};
        \draw[->,draw=PaleGray] (0,-.1)--(0,1.35) node[above] {$x_2$};
        \fill[MutedBlue] (0,1) circle (2.3pt);
        \fill[MutedBlue] (1,0) circle (2.3pt);
        \draw[DeepNavy,fill=CardWhite,line width=.8pt] (0,0) circle (2.5pt);
        \draw[DeepNavy,fill=CardWhite,line width=.8pt] (1,1) circle (2.5pt);
        \node[left] at (0,1) {1};
        \node[below] at (1,0) {1};
        \node[below left] at (0,0) {0};
        \node[above right] at (1,1) {0};
      \end{tikzpicture}
\par
\endgroup
\medskip
\begingroup
\paragraph{排他的論理和}
        入力が異なるときだけ1です。対角に同じクラスが置かれるため、どの一本の直線でも両群を分けられません。

\paragraph{必要な表現}
        入力を定数倍と足し算だけでは表せない形へ変える\term{非線形な変換}、複数の線形境界、変換する層を重ねたネットワークなどで、中間表現を作る必要があります。

\paragraph{教訓}
        学習則を長く回すだけでは、モデルが表現できない境界を学べません。

\par
\endgroup
\par
\endgroup


\section{ニューロン}
\label{sec:06-machine-learning-17}

入力の重み付き和へ非線形な関数を適用する計算単位を\term{人工ニューロン}、略してニューロンと呼びます。生物の神経細胞から着想した名前ですが、ここで扱うのは数式による単純化です。一つは単純でも、層として組み合わせると、入力を何段階も別の表現へ写せます。このようなニューロンの接続を\term{ニューラルネットワーク}といいます。

\begingroup
\begingroup
      \centering
      \begin{tikzpicture}[node distance=7mm,every node/.append style={font=\scriptsize}]
        \node[box] (x) {$\mathbf{x}$};
        \node[accentbox,right=of x] (z) {$z=\mathbf{w}^\top\mathbf{x}+b$};
        \node[box,right=of z] (a) {$a=\phi(z)$};
        \draw[flow] (x)--(z);
        \draw[flow] (z)--(a);
      \end{tikzpicture}
      \vspace{5mm}
\paragraph{活性化関数}
        重み付き和$z$へ適用する非線形関数$\phi$を\term{活性化関数}といいます。\term{ReLU}はRectified Linear Unitの略で、$z$が負なら0、正ならそのまま返す関数です。\term{シグモイド}は出力を0から1の間へ、\term{tanh}はhyperbolic tangent、すなわち双曲線正接という関数で、出力を$-1$から1の間へ滑らかに収めます。ここでは、入力をどの範囲の出力へ変えるかに注目すれば十分です。用途と層の役割に応じて選びます。

\par
\endgroup
\medskip
\begingroup
\paragraph{多層化}
        同じ段で並行して計算するニューロンのまとまりを\term{層}といいます。前の層の出力を次の層へ渡し、複数の変換をつなげます。入力と最終出力の間にあり、外から直接の正解を与えない層が\term{隠れ層}で、入力から中間表現を作ります。

\paragraph{非線形性の必要}
        線形変換だけを何層重ねても、全体は一つの線形変換にまとめられます。非線形活性化が表現を広げます。

\par
\endgroup
\par
\endgroup


\section{順伝播}
\label{sec:06-machine-learning-18}

利用者の質問へ答える推論時には、入力が最初の層から最後の層へ一方向に進みます。各層が前の表現を受け取り、重みと活性化関数で次の表現へ変える計算が\term{順伝播}です。「順」は入力から出力への向きを表します。

\begingroup
  \centering
  \begin{tikzpicture}[node distance=4mm,every node/.append style={font=\scriptsize}]
    \node[box] (x) {入力$\mathbf{x}$};
    \node[accentbox,right=of x] (h1) {隠れ層1};
    \node[accentbox,right=of h1] (h2) {隠れ層2};
    \node[box,right=of h2] (out) {予測$\hat{\mathbf{y}}$};
    \node[box,right=of out] (loss) {損失$\ell(\hat{\mathbf{y}},\mathbf{y})$};
    \draw[flow] (x)--(h1); \draw[flow] (h1)--(h2);
    \draw[flow] (h2)--(out); \draw[flow] (out)--(loss);
  \end{tikzpicture}
  \vspace{5mm}
\begingroup
\paragraph{順伝播}
        入力から層を順に計算し、最終出力を得ます。学習時も推論時も予測計算の向きは同じです。

\par
\endgroup
\medskip
\begingroup
\paragraph{損失計算}
        予測と目標の差を、一個の数である\term{スカラー}へまとめます。訓練データから一度の更新に使う小さな例の集合を\term{ミニバッチ}といい、例ごとの損失を平均するなどして目的を作ります。

\par
\endgroup
\par
\endgroup


\section{勾配降下法}
\label{sec:06-machine-learning-19}

順伝播で予測と損失を得たら、学習時には損失を小さくする方へ重みを動かします。勾配が示す上り坂と逆へ少しずつ進む最適化方法が\term{勾配降下法}です。どれだけ進むかが大きすぎても小さすぎても、学習はうまく進みません。

\begingroup
\begingroup
\paragraph{基本更新}
        勾配降下法は、現在のパラメータから勾配と反対方向へ学習率だけ進めます。
        \[
          \boldsymbol{\theta}_{t+1}
          =\boldsymbol{\theta}_{t}
          -\eta\nabla_{\boldsymbol{\theta}}
          L(\boldsymbol{\theta}_{t})
        \]
        下付きの$t$は何回目の更新かを示します。$\eta$は学習率です。大き過ぎると最小値を飛び越して値が増え続ける\term{発散}が起き、小さ過ぎると進行が遅くなります。

\paragraph{確率的勾配}
        全訓練例ではなく、無作為に選んだ一例またはミニバッチで勾配を近似する方法を\term{確率的勾配降下法}といいます。一回の計算を小さくする代わりに、選ばれた例によって勾配が揺れます。

\par
\endgroup
\medskip
\begingroup
\paragraph{実用的な最適化}
        \term{Momentum}は英語で勢いを意味し、過去の勾配の移動平均を使って、同じ方向へ進む動きを残す方法です。\term{Adam}はAdaptive Moment Estimationに由来する名前で、勾配の平均と、勾配を二乗した値の平均を推定し、パラメータごとの更新幅を調整します。直近の値ほど強く反映する平均が\term{移動平均}、二乗値の平均がここでいう\term{二次モーメント}です。どちらも、基本の勾配へ過去の情報を加えて更新を安定させる方法です。

\paragraph{監視する量}
        訓練・検証損失、勾配の大きさ、学習率、計算時間を追い、発散、停滞、過学習を切り分けます。

\par
\endgroup
\par
\endgroup


\section{誤差逆伝播}
\label{sec:06-machine-learning-20}

深いモデルには膨大な重みがあり、それぞれを別々に少し変えて試すのは非効率です。出力側で測った損失から、関数のつながりに沿って後ろから前へ計算し、各重みの勾配を求める方法が\term{誤差逆伝播}です。backpropagationを縮めて逆伝播とも呼びます。順伝播の計算経路を、学習時だけ逆向きにたどります。

\begingroup
\begingroup
\paragraph{連鎖律}
        $z=f(x)$、$L=g(z)$なら、
        \[
          \frac{dL}{dx}
          =\frac{dL}{dz}\frac{dz}{dx}
        \]
        です。関数を重ねたとき、外側の微分と内側の微分を掛けるこの規則が\term{連鎖律}です。値と演算の依存関係を節点と矢印で表した\term{計算グラフ}上で、各演算の微分を出力側から掛け合わせます。

\paragraph{逆向きの計算}
        順伝播で中間値を保存し、損失から入力側へ勾配を伝えます。共通する部分計算を再利用します。

\par
\endgroup
\medskip
\begingroup
\paragraph{役割の区別}
        逆伝播は勾配を計算する方法です。その勾配を使ってパラメータをどう変えるかを実装した仕組みが\term{最適化器}で、勾配降下法、Momentum、Adamなどがあります。

\paragraph{数値上の課題}
        多数の小さな微分を掛けて勾配がほぼ0になることを\term{勾配消失}、大きな微分を掛けて極端に大きくなることを\term{勾配爆発}といいます。学習開始時の重みを適切に決めることが\term{初期化}、値の大きさの尺度をそろえることが\term{正規化}、層へ入った値を変換後の出力へ足して先へ渡す接続が\term{残差接続}です。これらを使って学習を安定させます。

\par
\endgroup
\par
\endgroup


\section{系列データ}
\label{sec:06-machine-learning-21}

時間順の値や文中の語のように、並び順が意味を持つデータを\term{系列データ}といいます。質問文では「明日」「届く」の順序や、離れた位置にある「注文番号1234」と述語の関係が意味を左右します。長さが一定でない列の中で、順序と遠い依存をどう保つかが次の課題です。

\begingroup
\begingroup
\paragraph{長距離依存}
        系列内で遠く離れた位置同士の関係を\term{長距離依存}といいます。文頭の主語や定義が、後方の語の解釈へ影響するため、必要な情報を長く保持する必要があります。

\par
\endgroup
\medskip
\begingroup
\paragraph{可変長}
        文や時系列の長さは一定ではありません。複数の例を同じ形へ並べて一度に計算することを\term{バッチ化}といいます。短い列の後ろへ意味のない値を足して長さをそろえる\term{パディング}と、その位置を計算対象から外す\term{マスク}を使います。

\par
\endgroup
\medskip
\begingroup
\paragraph{順序}
        同じ要素でも並び順が変われば意味が変わります。各位置の情報を表現へ入れます。

\par
\endgroup
  \vspace{5mm}
\paragraph{逐次計算との違い}
    \term{RNN}はRecurrent Neural Network、すなわち再帰型ニューラルネットワークの略です。一つ前の位置の状態を受け取って次を計算するため、系列方向の計算を同時に進めにくくなります。後で説明するTransformerは、Attentionによって位置同士を直接結び、訓練時に同時に行える計算を増やします。

\par
\endgroup


\section{Attention}
\label{sec:06-machine-learning-22}

系列を左から一語ずつ一つの状態へ押し込む代わりに、いま処理している位置が、入力中の各位置をどれだけ参照するか計算します。この仕組みが\term{Attention}で、日本語では注意機構と呼びます。「届く」を処理するとき「注文番号1234」や「いつ」へ大きな重みを与えるように、内容に応じて情報の集め方を変えます。

\begingroup
\begingroup
      \centering
      \begin{tikzpicture}[node distance=5mm,every node/.append style={font=\scriptsize}]
        \node[accentbox] (q) {現在位置};
        \node[box,right=of q,yshift=13mm] (v1) {位置1\\重み .1};
        \node[box,right=of q] (v2) {位置2\\重み .7};
        \node[box,right=of q,yshift=-13mm] (v3) {位置3\\重み .2};
        \draw[softflow] (q)--(v1);
        \draw[flow,line width=1.1pt] (q)--(v2);
        \draw[softflow] (q)--(v3);
      \end{tikzpicture}
\par
\endgroup
\medskip
\begingroup
\paragraph{内容に応じた参照}
        現在の表現と各位置の表現を比べ、どれほど合うかを\term{適合度}という数で表します。複数の適合度をすべて正の値にし、合計が1になるよう変換する関数が\term{softmax}です。結果を各位置へ割り当てる重みとして使います。

\paragraph{出力}
        各位置が持つ内容のベクトルを、softmaxで得た重みによって重み付き和にします。系列長が異なっても、一位置あたり同じ次元数のベクトルへ、必要な位置の情報を集約できます。

\par
\endgroup
  \vspace{4mm}
  \takeaway{重みはモデル内部の計算結果です。人間の説明や因果関係と常に一致するとは限りません。}
\par
\endgroup


\section{Query・Key・Value}
\label{sec:06-machine-learning-23}

参照の計算を、探したいもの、各位置が持つ手掛かり、実際に取り出す内容へ分けます。それぞれを\term{Query}、\term{Key}、\term{Value}と呼びます。データベース検索の「問い合わせ、検索用の鍵、得たい値」になぞらえた名前です。QueryとKeyの合い方が重みを決め、その重みでValueを混ぜると、現在位置に必要な文脈が集まります。

\begingroup
\begingroup
\paragraph{Query}
        Queryは「問い合わせ」を意味し、現在位置がどのような情報を必要としているかを表すベクトルです。

\par
\endgroup
\medskip
\begingroup
\paragraph{Key}
        Keyは「鍵」を意味し、各位置がどのQueryと合うかを比較するためのベクトルです。暗号鍵ではなく、検索の照合に使う見出しに近い役割です。

\par
\endgroup
\medskip
\begingroup
\paragraph{Value}
        Valueは「値」を意味し、適合した位置から実際に取り出して混ぜる内容のベクトルです。

\par
\endgroup
  \vspace{5mm}
\paragraph{Scaled Dot-Product Attention}
        \term{Scaled Dot-Product Attention}は「尺度調整した内積によるAttention」という意味です。QueryとKeyの内積で適合度を求め、Keyの次元数$d_k$の平方根で割り、softmaxで重みに変えてValueを集約します。
        \[
      \operatorname{Attention}(Q,K,V)
      =\operatorname{softmax}
      \left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V
    \]
    次元数が増えると内積の絶対値も大きくなりやすいため、$1/\sqrt{d_k}$で尺度を調整します。$M$は、参照してはいけない位置の適合度を事実上選ばれない値へ変えるマスクです。$Q$、$K$、$V$は複数位置のベクトルを行列へまとめたものです。

  \source{Vaswani et al., “Attention Is All You Need”, 2017}
\par
\endgroup


\section{Self-Attention}
\label{sec:06-machine-learning-24}

同じ系列の各位置からQuery、Key、Valueを作り、その系列内の位置同士を参照させる仕組みが\term{Self-Attention}です。selfは参照元と参照先が同じ系列であることを表します。質問文の各単位が互いを参照できます。

\begingroup
  \centering
  \begin{tikzpicture}[node distance=4mm,every node/.append style={font=\scriptsize}]
    \node[box] (x) {入力$X$};
    \node[accentbox,right=of x,yshift=12mm] (q) {$Q=XW_Q$};
    \node[accentbox,right=of x] (k) {$K=XW_K$};
    \node[accentbox,right=of x,yshift=-12mm] (v) {$V=XW_V$};
    \node[box,right=17mm of k] (attn) {Attention};
    \draw[flow] (x)--(q); \draw[flow] (x)--(k); \draw[flow] (x)--(v);
    \draw[flow] (q)--(attn); \draw[flow] (k)--(attn); \draw[flow] (v)--(attn);
  \end{tikzpicture}
  \vspace{4mm}
\begingroup
\paragraph{Multi-Head Attention}
        入力へ行列を掛け、目的に合う別の表現へ写す変換を\term{射影}と呼びます。異なる射影でQuery、Key、Valueを複数組作り、それぞれAttentionを計算して最後に結合する仕組みが\term{Multi-Head Attention}です。一組を\term{ヘッド}と呼び、語の関係、指示先、位置の近さなど異なる結び付きを並行して表せます。

\par
\endgroup
\medskip
\begingroup
\paragraph{計算量}
        標準的なSelf-Attentionは$n$個の各位置と$n$個の全位置を比べます。適合度を並べる行列は$n\times n$となるため、計算量とメモリ量の主要部分が$O(n^2)$です。長い文脈ではこの二乗の増え方が課題になります。

\par
\endgroup
\par
\endgroup


\section{位置情報}
\label{sec:06-machine-learning-25}

Attentionの重みは内容の関係を見ますが、そのままでは語順を自動的に区別しません。「AIが注文を確認する」と「注文がAIを確認する」を分けるため、各トークンがどこにあるかを表現へ加えます。

\begingroup
\begingroup
\paragraph{なぜ必要か}
        位置表現を持たないSelf-Attentionは、入力の並べ替えに応じて出力も同様に並べ替わる性質を持ちます。語順自体を区別する情報が必要です。

\paragraph{入力へ加える方式}
        波の形を表す数学関数である正弦と余弦を使い、位置ごとに異なるベクトルを作る方式が\term{位置エンコーディング}です。元論文ではこのベクトルを入力へ加えます。位置番号ごとのベクトル自体をパラメータとして学ぶ\term{位置埋め込み}も使われます。

\par
\endgroup
\medskip
\begingroup
\paragraph{相対位置}
        各位置の絶対番号ではなく、二位置がいくつ離れ、どちらが先かを使うものが\term{相対位置}の方式です。ベクトルの成分を位置に応じて回転させ、内積へ相対距離を反映する回転位置埋め込みなど、実装はモデルごとに異なります。

\paragraph{長さの外挿}
        観測・学習した範囲の外側へ規則を延ばして予測することを\term{外挿}といいます。学習時より長い系列へそのまま正しく一般化できるとは限らないため、位置方式と学習条件を確認します。

\par
\endgroup
\par
\endgroup


\section{Transformerの構成}
\label{sec:06-machine-learning-26}

Attention、位置情報、各位置で同じように行うニューラルネットワークの変換、層の入力を変換後の出力へ足す残差接続、値の尺度を整える正規化を一まとまりとして重ねたモデルが\term{Transformer}です。transformは「変換する」を意味します。前の節までに見た小さな操作が、長い文脈を変換する一つのモデルへまとまります。

入力全体を読み、各位置の文脈表現を作る部分を\term{Encoder}、日本語では符号化器と呼びます。すでに生成した位置を使って次の位置を作る部分を\term{Decoder}、復号器と呼びます。ここでの符号化・復号は暗号化ではなく、ある表現を別の表現へ変える役割名です。

\begingroup
  \noindent
  \begin{tabularx}{\textwidth}{@{}lYYY@{}}
    \toprule
    構成 & 参照範囲 & 主な出力 & 代表的な用途\\
    \midrule
    Encoder & 入力系列の前後を参照 & 各位置の文脈表現 & 分類、検索用表現\\
    Encoder--Decoder & Encoder出力と生成済み出力 & 条件付きの次トークン & 翻訳、要約\\
    Decoder-only & 因果マスクで過去位置だけ参照 & 次トークン分布 & 継続生成、対話\\
    \bottomrule
  \end{tabularx}
  \vspace{4mm}
\paragraph{構成と能力}
    表の\term{因果マスク}は、次トークンを予測する位置から未来の正解トークンを参照できないよう隠すマスクです。Encoderだけ、EncoderとDecoder、Decoderだけという構成があり、学習目的、データ、規模、位置表現、推論方法によって性質は変わります。

  \source{Stanford CS224N, “Transformers” lecture}
\par
\endgroup


\section{トークン化}
\label{sec:06-machine-learning-27}

モデルの構造ができても、入力はまだ文字列です。文字列を、モデルが扱う小さな単位へ分ける処理が\term{トークン化}で、その一単位が\term{トークン}です。各トークンへ重複しない整数の識別番号、すなわち\term{トークンID}を割り当てます。ネットワークが運んだ文字列は、ここで番号の列になります。

モデルが使用できる全トークンとIDの対応表を\term{語彙}といいます。トークンIDを使ってこの表とモデル内の表を引き、各トークンをベクトルへ変えます。この学習可能なベクトルが\term{トークン埋め込み}です。

\begingroup
  \centering
  \begin{tikzpicture}[node distance=4mm,every node/.append style={font=\scriptsize}]
    \node[accentbox] (text) {「情報工学を学ぶ」};
    \node[box,right=of text] (pieces) {情報｜工学｜を｜学ぶ};
    \node[box,right=of pieces] (ids) {318, 9042, 17, 771};
    \draw[flow] (text)--(pieces);
    \draw[flow] (pieces)--(ids);
  \end{tikzpicture}
  \vspace{5mm}
\begingroup
\paragraph{トークンの単位}
        トークンは単語とは限りません。よく現れる単語の一部である\term{部分語}、一文字、またはバイト列を組み合わせます。そのため、日本語で人が考える語の境界と一致しない場合があります。

\par
\endgroup
\medskip
\begingroup
\paragraph{影響}
        同じ文字数でもトークン数は言語や文字列で変わります。文脈長、料金、生成可能な単位へ影響します。

\par
\endgroup
  {\scriptsize 図の分割とIDは説明用です。実際の語彙と分割はモデルごとに異なります。}
\par
\endgroup


\section{次トークン予測}
\label{sec:06-machine-learning-28}

\term{言語モデル}は、これまでのトークン列が与えられたとき、次に各トークンが続く確率を計算するモデルです。完成した答えを一度に取り出すのではありません。学習時には、実際に続いたトークンの確率が高くなるようパラメータを更新します。この\term{次トークン予測}を大量の文へ繰り返します。

\begingroup
\begingroup
\paragraph{自己回帰分解}
        自分がそれまでに扱った値を条件に、次の値を一つずつ予測する方式を\term{自己回帰}といいます。系列全体の確率は、それ以前のトークンを条件とする次トークン確率の積へ分けられます。
        \[
          P(t_1,\ldots,t_n)
          =\prod_{i=1}^{n}
          P(t_i\mid t_1,\ldots,t_{i-1})
        \]
        各位置で、それ以前のトークンから正解トークンの確率を高くします。

\paragraph{学習信号}
        パラメータをどちらへ変えるか知らせる正解情報を\term{学習信号}といいます。一つの系列では、各位置の実際の次トークンが正解になるため、多数の「それまでの文脈→次トークン」の例を作れます。交差エントロピーによって、正解トークンへ高い確率を割り当てるよう学習します。

\par
\endgroup
\medskip
\begingroup
\paragraph{大規模事前学習}
        特定の一アプリへ組み込む前に、大量で多様な文書やコードを使って共通の予測課題を学ぶことが\term{事前学習}です。データとパラメータ数と計算量を大きくしたものを大規模事前学習と呼び、言葉の並び方やデータ中の知識を統計的な傾向としてパラメータへ反映します。

\paragraph{モデルと事実}
        記憶、一般化、混同が同じ生成過程に現れます。学習目的は個々の出力の真偽を直接保証しません。

\par
\endgroup
\par
\endgroup


\section{プロンプトとコンテキスト}
\label{sec:06-machine-learning-29}

推論時にモデルへ与え、どんな出力を求めるか伝える文字列やデータを\term{プロンプト}といいます。モデルが一回の生成で参照できる入力と、それまでに生成したトークン全体が\term{コンテキスト}です。質問だけでなく、注文サービスが返した「到着予定は明日午後」という事実、指示、会話履歴を一つの列へ組み、答えの根拠を渡します。

\begingroup
\begingroup
\paragraph{含まれるもの}
        実行してほしいことを示す指示、利用者の質問、会話履歴、期待する入出力の例、検索で取得した文書、別のプログラムを呼んだ結果などをトークン列としてモデルへ渡します。

\paragraph{重みとの違い}
        通常のプロンプトは推論時の条件を変えますが、学習済みパラメータ自体を書き換えません。

\par
\endgroup
\medskip
\begingroup
\paragraph{有限の文脈長}
        一回で扱える入力と出力の最大トークン数を\term{文脈長}といいます。計算量とメモリ量に限りがあるため上限があります。長い文書では必要部分の選択、短縮して意味を残す要約、関連箇所の検索、複数回への分割が必要です。

\paragraph{指示の競合}
        複数の指示が互いに両立しないことを\term{指示の競合}といいます。取得文書の中に指示のような文字列がある場合も、期待する優先順位で処理されない可能性があります。どの範囲が命令でどの範囲が資料かという入力境界と、どの情報源を信頼するかを管理します。

\par
\endgroup
\par
\endgroup


\section{文章生成}
\label{sec:06-machine-learning-30}

コンテキストを受けたモデルは、語彙中の各候補へ、確率へ変換する前の点数を出します。この点数を\term{ロジット}といい、softmaxで確率分布へ変えます。そこから一つを選び、列へ足して再び計算します。「明日」「の」「午後」と一歩ずつ進み、停止条件へ達したとき、利用者へ返す一文が完成します。

\begingroup
  \centering
  \begin{tikzpicture}[node distance=3mm,every node/.append style={font=\scriptsize}]
    \node[accentbox] (ctx) {文脈};
    \node[box,right=of ctx] (logits) {logits};
    \node[box,right=of logits] (prob) {softmax\\確率};
    \node[box,right=of prob] (select) {選択};
    \node[accentbox,right=of select] (next) {次トークン};
    \draw[flow] (ctx)--(logits); \draw[flow] (logits)--(prob);
    \draw[flow] (prob)--(select); \draw[flow] (select)--(next);
    \draw[softflow] (next.south) to[bend left=25] node[below]{文脈へ追加して反復} (ctx.south);
  \end{tikzpicture}
  \vspace{5mm}
\begingroup
\paragraph{貪欲選択}
        毎回、最も確率が高い一候補を選ぶ方法が\term{貪欲選択}です。同じ条件なら結果を再現しやすい一方、その時点で二番目以下の候補を捨てるため、文全体で最も良い列になるとは限りません。

\par
\endgroup
\medskip
\begingroup
\paragraph{サンプリング}
        確率に従う抽選で候補を選ぶことを\term{サンプリング}といいます。\term{温度}はロジットの差を調整する値で、高くすると分布が平らになり多様な候補が選ばれやすくなります。top-$k$は確率上位$k$個だけを候補にし、top-$p$は確率を上から足して合計が$p$へ達する最小の候補集合を使います。同じ入力でも結果が変わり得ます。

\par
\endgroup
\medskip
\begingroup
\paragraph{停止}
        モデルが文の終了を表す特別な終了トークンを選ぶ、設定した最大長へ達する、指定した停止文字列が出る、という条件で生成を終えます。停止条件がなければ、必要な答えを越えて生成し続ける可能性があります。

\par
\endgroup
\par
\endgroup


\section{評価}
\label{sec:06-machine-learning-31}

応答が自然に読めるだけでは、配送予定として正しいとは言えません。モデルやアプリが目的をどれだけ果たすかを、決めた条件と指標で確かめることが\term{評価}です。固定した質問群で、注文データとの一致、答えられない場合の扱い、遅延、費用などを測ります。

\begingroup
\begingroup
\paragraph{分類の例}
        全例のうち正しく分類した割合が\term{Accuracy}、陽性と予測した例のうち本当に陽性だった割合が\term{Precision}、実際の陽性例のうち見つけられた割合が\term{Recall}です。\term{F1}はPrecisionとRecallの両方を一つへまとめ、一方だけ低いと値が下がる指標です。

        しきい値を動かしたときの、陽性を見つける割合と陰性を誤って陽性にする割合を描いたものがROC曲線で、その曲線下の面積が\term{ROC-AUC}です。PrecisionとRecallの関係を描いたPR曲線の下側の面積が\term{PR-AUC}です。AUCはArea Under the Curve、すなわち曲線下の面積を意味します。陽性と陰性の件数比、誤りの影響、確率の校正に応じて指標を選びます。

\paragraph{生成の例}
        あらかじめ用意した正解との一致、引用元が実際に主張を支えるか、事実と合うか、利用者の課題を達成したか、人が基準に沿って付ける評価、応答時間、費用など複数の軸を使います。文章には正しい表現が複数あり得るため、一つの文字列との一致だけでは十分ではありません。

\par
\endgroup
\medskip
\begingroup
\paragraph{ベースライン}
        新しい方法の価値を測る比較基準を\term{ベースライン}といいます。最も多いクラスを常に返す方法、単純な規則、既存システム、小さなモデルと比べ、増えた複雑さに見合う改善かを確かめます。

\paragraph{評価集合}
        評価に使う入力と期待結果の集まりが\term{評価集合}です。実運用でよく現れる例だけでなく、影響の大きい失敗、許される範囲の端、意図的に誤動作を狙う入力を含めます。

        有限の標本から計算した指標には揺れがあります。その不確実さを「同じ方法で標本を取り直したとき、決めた割合で真の値を含むよう作る区間」などとして示すものが\term{信頼区間}です。区間の計算方法、標本数、前提を合わせて示します。

\par
\endgroup
\par
\endgroup


\section{データ漏洩と偏り}
\label{sec:06-machine-learning-32}

高い評価値が出ても、答えを含むデータが評価側へ漏れていたり、利用者や質問の一部だけが多く含まれていたりすれば、実際の力を表しません。データがどこから来て、どの単位で分かれ、誰を代表するかまで流れをたどります。

\begingroup
\begingroup
\paragraph{データ漏洩}
        予測時には得られない情報が学習やモデル選択へ入り、評価を実際より良く見せることが\term{データ漏洩}です。未来情報、正解ラベルから作った特徴、訓練とテストにまたがる重複例、全データから計算した平均などが例です。

\paragraph{防止}
        欠損値の補完や値の尺度調整など、モデルへ渡す前の変換を\term{前処理}といいます。まずデータを分割し、前処理で必要な平均なども訓練データだけから求めます。利用者、時系列、元文書の単位で重複を除き、生成AIでは評価問題そのものが訓練データへ入っていないかも調べます。

\par
\endgroup
\medskip
\begingroup
\paragraph{データの偏り}
        収集したデータが、利用対象の集団や状況を均等または目的に合う形で表していないことを\term{データの偏り}といいます。収集対象、測定方法、注釈基準、過去の判断が、集団ごとの例数と誤りへ影響します。

\paragraph{分解評価}
        全体平均を、利用条件、言語、期間、重要な集団などの部分へ分けて測ることが\term{分解評価}です。全体では良く見えても、一部の利用者だけ失敗が多い問題を見つけます。

\par
\endgroup
\par
\endgroup


\section{分布変化とハルシネーション}
\label{sec:06-machine-learning-33}

公開後には、新しい商品、配送規則、言い回しが現れます。訓練・評価時と運用時で、入力や正解との関係を表す確率分布が変わることを\term{分布変化}といいます。言語モデルは確からしい続きを作る仕組みなので、注文データにない日時を流暢に補うこともあります。

\begingroup
\begingroup
\paragraph{分布変化}
        季節、製品、利用者行動、入力装置が変わると、訓練時に学んだ入力と正解の関係が崩れる場合があります。運用中の入力の傾向と、正解を確認できた例の性能を継続して監視します。

\par
\endgroup
\medskip
\begingroup
\paragraph{ハルシネーション}
        言語モデルが、流暢でも入力や信頼できる資料に根拠のない内容、存在しない引用、矛盾を生成する現象を\term{ハルシネーション}と呼びます。英語で幻覚を意味する語ですが、モデルが人のように知覚しているという意味ではありません。検索結果を加えても、読み違いや無視があるため無条件には防げません。

\par
\endgroup
\medskip
\begingroup
\paragraph{人間の確認}
        医療、法務、金融、安全、個人情報、不可逆な操作など、誤りの影響が大きい判断では権限ある人が検証します。

\par
\endgroup
  \vspace{5mm}
\paragraph{運用上の制御}
    出典の照合、入力・出力検査、権限分離、操作前確認、誰がいつ何をしたかを後から追える\term{監査ログ}、停止手段、モデルを使えないときの代替手順を組み合わせます。
    モデルの確信表現だけを検証の代わりにしません。

\par
\endgroup


\section{手を動かす：学習と汎化}
\label{sec:06-machine-learning-34}

言語モデル全体を訓練しなくても、学習データへ合うことと未知データへ通用することの違いは小さな回帰で観測できます。曲線の次数を変え、訓練誤差が下がってもテスト誤差が上がる地点を探します。

\begingroup
\begingroup
      \begin{lstlisting}[language=Python,basicstyle=\ttfamily\fontsize{6.8}{8.1}\selectfont]
import numpy as np

def mse(y, pred):
    return np.mean((y - pred) ** 2)

# train_x, train_y, test_x, test_y は事前に分割済み
for degree in [0, 1, 3, 9]:
    w = np.polynomial.polynomial.polyfit(
        train_x, train_y, degree
    )
    train_pred = np.polynomial.polynomial.polyval(
        train_x, w
    )
    test_pred = np.polynomial.polynomial.polyval(
        test_x, w
    )
    print(degree, mse(train_y, train_pred),
          mse(test_y, test_pred))
      \end{lstlisting}
\par
\endgroup
\medskip
\begingroup
\paragraph{記録と考察}
        \term{MSE}はMean Squared Error、すなわち平均二乗誤差の略で、各残差を二乗して平均した値です。次数、訓練MSE、テストMSE、曲線を記録します。

        コンピュータの疑似乱数は、開始値が同じなら同じ列を再現できます。この開始値を\term{乱数シード}といいます。シードとデータ分割を固定して条件をそろえ、テスト誤差が増える次数を探します。

\paragraph{追加課題}
        重みへL2正則化を加えた線形回帰である\term{Ridge回帰}を試します。同じ次数で、正則化の強さを表す係数を検証データから選びます。

\par
\endgroup

\section{応答を返す}
\label{sec:06-machine-learning-35}

入力文はトークンとベクトルへ変わり、Transformerの層を通って次トークンの分布になりました。モデルは注文サービスから渡された事実を含むコンテキストを参照し、「明日の午後に到着する予定です」と一語ずつ生成します。学習時には損失と勾配が重みを形作り、推論時には固定した重みの上を入力が順方向へ進みます。

ただし、流暢さは事実性の保証ではありません。評価集合、出典との照合、入力と出力の検査、失敗時の代替がアプリ側に必要です。完成した文はHTTP応答へ入り、ネットワークを戻ろうとしています。最終章では、その帰り道を含めて全層を一度につなぎ、問題が起きたときの戻り方を考えます。

\takeaway{モデルの応答は、言葉を直接理解する魔法ではなく、数値表現を層ごとに変換し、文脈に続くトークンを確率的に選ぶ計算の結果です。}


\section{旅をたどり直す}
\label{sec:06-machine-learning-36}

質問の文字列がトークンになり、数値計算を経て再び文字列になるまでをたどり直します。次の問いでは、学習と推論、予測と判断、流暢さと正しさの境界を混同しないよう説明してください。

\begingroup
  \begin{enumerate}
    \item 勾配と負の勾配は、損失関数上でどの方向を示しますか。
    \item 検証データとテストデータの用途を分ける理由を説明してください。
    \item 多項式の次数を上げると、訓練誤差と未知データ誤差はどうなり得ますか。
    \item 確率0.5以外を分類しきい値に選ぶ例を示してください。
    \item パーセプトロンがXORを学習できない理由を説明してください。
    \item 逆伝播と勾配降下法は、それぞれ何を行いますか。
    \item Self-Attentionに位置情報が必要な理由を説明してください。
    \item Decoder-onlyモデルで因果マスクが防ぐ参照は何ですか。
    \item 次トークン予測が、出力の事実性を保証しない理由を説明してください。
    \item 生成AIを高影響の操作へ使う際の制御を三つ挙げてください。
  \end{enumerate}
