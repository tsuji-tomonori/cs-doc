# 第5章 インターネットという分散網 改訂設計メモ

## 章の狙い

ネットワークを、単なる通信手順ではなく、パケット交換・階層化・IP・ルーティング・AS・IX・BGP・DNS・エンドツーエンド原則によって成り立つ分散網として説明します。

## 本文で必ず書くこと

- 通信性能は帯域幅だけでなく、遅延、RTT、待ち行列、損失、再送の前提になることを示します。
- 回線交換とパケット交換を独立節にし、インターネットがなぜパケットを単位にするかを説明します。
- IPは信頼性を保証しないベストエフォートのデータグラム配送であり、その上の層が足りない性質を補う構造として説明します。
- インターネットは単一の巨大組織ではなく、ISP・AS・IXが相互接続する網の網であることを明確にします。
- DNSは階層委任とキャッシュを持つ分散データベースの例として扱い、dig +traceで観測できるようにします。
