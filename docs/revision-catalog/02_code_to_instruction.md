# 第2章 コードから命令へ 改訂設計メモ

## 章の狙い

人間が書くソースコードが、トークン、構文、AST、評価順、機械語・実行方式へ変換される流れを扱います。第1章のCPU命令と、第3章のプロセス実行を接続します。

## 本文で必ず書くこと

- 命令セット・機械語・アセンブリを、CPUが実行できる約束として説明します。
- 高級言語は人間にとって扱いやすい抽象化であり、コンパイルやインタプリタを通じて実行可能な形になることを示します。
- 字句解析・構文解析・ASTは、文字列を意味のある構造に変換する処理として説明し、第8章のHTML解析との対応を張ります。
- 木構造・再帰・DFS/BFSをAST評価の文脈から説明し、単なるアルゴリズムの羅列にしません。
