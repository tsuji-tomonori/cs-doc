# はじめに 改訂設計メモ

## 章の狙い

一つの送信を起点に、物理層・実行環境・設計・分散網・LLM・ブラウザ描画までの流れを示します。既存教材の問いを維持しつつ、章の分割と新設に合わせて場面数と図の責務を更新します。

## 本文で必ず書くこと

- 「注文番号1234はいつ届きますか」という一要求を、押下・送信・経路・処理・生成・描画の各場面に分解します。
- 読者が新卒アプリケーションエンジニアであることを前提に、数式や回路を目的化せず、実務で調査や設計判断に戻れる地図として説明します。
- 9章構成へ変わるため、九つの場面を、第1章から第9章までの対応が一目で分かる俯瞰図にします。
- 本書全体のルールとして、専門用語は初出で太字、略語は正式名称・役割・本書内での使い方の順に説明します。
