# 第3章 プログラムが動く場所 改訂設計メモ

## 章の狙い

実行中のプログラムを、OS、プロセス、システムコール、仮想メモリ、型、データ構造、計算量の観点から説明します。コードがCPU命令になるだけでは不十分で、どこで、どの資源を使って動くかを扱います。

## 本文で必ず書くこと

- OSを、ハードウェア資源を安全に分配し、アプリに共通の実行環境を与えるものとして説明します。
- プロセス・アドレス空間・仮想メモリを、同時に複数のプログラムが動くための分離の仕組みとして扱います。
- ポインタ・参照・型・値渡しは、Goの具体例で説明し、Pythonのオブジェクトモデルと比較します。
- 配列・スライス・マップは、メモリ配置と計算量の両面から、選択理由を説明できるようにします。
