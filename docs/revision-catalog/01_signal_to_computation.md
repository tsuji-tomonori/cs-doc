# 第1章 信号から計算へ 改訂設計メモ

## 章の狙い

電圧の揺らぎを0/1として扱うところから、NAND、加算器、記憶回路、メモリ階層、CPUの命令実行までを、アプリの一要求が最終的には物理信号で動くという視点で説明します。

## 本文で必ず書くこと

- アプリケーションの文字列や数値が、まずビット列として表され、論理値として処理されることを示します。
- トランジスタを詳細な半導体物性ではなく「電気で電気を制御するスイッチ」として抽象化します。
- NANDだけで論理回路を構成できることを、NOT/AND/ORの作成例と真理値表で説明します。
- 半加算器・全加算器・ALUをつなぎ、加算命令がCPU上で実行される最小限の道筋を作ります。
- SRAM/DRAMとメモリ階層は、速度・容量・コストのトレードオフとして扱い、第3章の仮想メモリへ橋渡しします。
